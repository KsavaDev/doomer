This is a version of the boomer applcation, originally created by Tsoding, rewritten in C and made independent of Window System.

# Dependecies

- ~ (Will be changed in future)
- OpenGL

# Quick start

```console
$ make
$ make install
```

# Why

(15.11.26) I sitting on hyprland and it supports zooming in/out. But for me it works kinda bad. I tried configure it out and it was bad. So I tried install boomer by tsoding. And I got X11 errors. Well, I dont get better idea than recreate it by myself and try figure it out how it works.

(23.11.26) Well, now I know, why I got errors. So I decided to make this application independent of Window System (as I said before).
